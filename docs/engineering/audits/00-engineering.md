## 新门禁核对

`tools/quality_gate.py` 以任务修改前指纹比较受管文件，记录范围、契约、验收、影响、实际审查方式、必需检查和待验项。它固定调用 `self`、`host`、`home`，不执行记录中的任意命令，不改设备/云/版本/Git。

24 个门禁测试已直接运行通过，覆盖正常文档与原有脏状态、新增/删除、范围越界、运行时伪装、未填模板、字段缺失、未知检查、坏基线、编码、输出位置、优化模式、子进程失败/超时、CLI 非零退出和验证期间源码变化。测试使用合成仓库；其中模拟失败是检查门禁逻辑，不是实际 Android 故障测试。

本批最终综合结果以 `analysis/engineering-governance/gate.json`、`checks/*.log` 为准；报告包含当前源码指纹、变更记录哈希、实际命令结果及日志哈希。故意越界的 CLI 检查另存 `negative-scope.json`，预期退出码为 1。

审查工具还核对规范相对链接、UTF-8 与 Git 可见性；结果保存 `repository-checks.json`。无需为了文档改动构建/安装。没有配置 CI 或 Git 钩子，工具只能保证被实际调用时的本地检查；这项限制已写入 AGENTS。
