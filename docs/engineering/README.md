`AGENTS.md` 是执行入口；上述文件是项目规范。现有代码与规范不符时登记遗留问题，禁止扩大新的违反；不要把“已有这种写法”视为继续复制的依据。

历史版本说明、`analysis/` 下证据、根目录旧状态记录和 01—05 设计文档保留其时间/版本范围。现有三层迁移设计是目标方案，当前运行实现主要仍为 Java/Android 原生和复用的官方 View/Compose 控件。没有完成迁移前，不用目标设计描述当前实现。

事实来源顺序：本次源码与受控实测 → 对应基线的测试/产物记录 → 标明版本的历史材料。设计文档只能证明设计意图。本规范建立时的交付基线为 1.0.114；后续实际交付以 APK 的 `.build.json` 和安装验收为准。`standalone-relay/version.txt` 保存下一次构建号，不能据此判断已安装版本。

规范变更也需记录原因、影响与验证。所有规则按风险使用，不追求文件数量、测试数量、抽象层数或某种框架本身；目标是可解释、可回归、可维护的行为。
