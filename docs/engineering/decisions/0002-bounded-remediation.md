# ADR-0002：分批修复已核实边界，不合并未验证的大型重构

日期：2026-10-24；状态：本轮采用，自审。用户授权逐项修复、运行简单测试，暂不能修复的保留标记；已连接设备可用于目标应用验收。

## 本批决策

1. 过渡对象未建立目标时拒绝接收内容；九类详情必须先 select 再注册。日历指标由页面显式传入，保留健康首页/综合趋势既有步数标记口径，未经需求讨论不改变综合统计含义。
2. 本机分析在一次任务中冻结设备、日期、时区和时间区间，贯穿刷新、加载与结果提交校验；保留旧探针的单次读取兼容入口，不改变算法和原始健康数据格式。
3. 原生观察器缓存对比当前 APK 内资产哈希，非空损坏文件安全重建。仅清理本应用对应缓存，不触及用户文件或运行其他 Root 操作。
4. 构建入口要求本次原始基线与变更记录，强制完整本地检查，失败先于 APK/版本写入。成功产物保存哈希与 preflight 关联清单。默认 D 盘 scratch，保留已有清理路径校验，原生子构建沿用本任务临时目录。

## 审查更正

上一轮单独求值日历路由表达式，将睡眠趋势归为错误步数路由，但未计入 TrendMetricActivity 在 metric=6 时先跳转 SleepDetailActivity 并结束自身。真实入口不会到达该错误分支。本轮更正为不可达分支，不再报告睡眠趋势真机故障；原始腕温确有路由问题。

## 暂缓边界

UI-003—006、DATA-001、LINK-001、SET-001 需要指标完整性、公共任务/页面所有者与绘制消费者的独立整改；不能只替换一个线程池或把 settled 全部改成 locallyReady 后销项。CLOUD-001 的其余规范转换及 CLOUD-002 的服务器条件写入语义缺少足够证据，先保留，不推测云协议或上传虚构数据。

## 验证和回退

先保存失败反例和分批门禁，再构建/签名，最后按实际设备执行隔离初始化/缓存检查与既有日期切换回归。主机、Android、真机与云验收分别记录。现有数据格式和偏好键保持兼容；回退只撤回本批差异，保留原脏工作区和旧 APK。构建接口新增参数是有意的流程约束，旧无记录构建命令将明确失败。
