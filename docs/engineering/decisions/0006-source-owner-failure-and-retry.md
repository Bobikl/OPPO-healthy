# 0006：归属读取失败与重试资格

2026-10-28；对应变更 `20261028-defensive-fixes`。

归属检查正常返回空值表示无当前会话、设备/账号未被验证等不适用情况，继续保留只归档原包的行为。凭据、历史副本或数据库读取抛错必须传递明确的 `SYNC_SOURCE_OWNER_READ`，不再当成正常空归属。

调用方先保留已收到的原包和本地投影，再把归属异常传回窗口同步层。该窗口不算完成，历史游标不推进；后续正常读取同一窗口时仍按当时已验证的身份创建事件。不得根据缺失归属推断账号，不新增无主事件队列，不追溯登录前历史为新账号上传。原有账号代次提交复核保持不变。

云重试采用已知临时故障：网络连接/超时/解析主机失败、HTTP 408/429/5xx 和同步预算让出。其他请求、协议、数据库和未知错误保留进度与分类提示，结束本轮自动重试。已有定时/充电/手动触发仍遵守原设置；SENDING/ACK_UNKNOWN 与回读确认不变。

没有数据库格式或数据迁移。回退本批代码即可恢复旧行为；已保存原包及已有上传事件保持原样。
