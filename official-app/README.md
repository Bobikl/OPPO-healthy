# 官方应用静态拆解文件

此目录保存开发适配时已经拆解出的官方应用代码、DEX、原生库和资源，与根目录下的独立应用源码分开。

## 目录

| 路径 | 内容 |
| --- | --- |
| `legacy/jadx-sources/` | 原有批量 JADX 反编译输出，保留包目录结构。输出中没有留存可靠的版本元数据，故单列为旧拆解资料。 |
| `legacy/targeted/` | 早期通知监听、消息转发和连接协议的专项反编译输出。 |
| `6.6.7/dex/` | 从适配用官方 6.6.7 APK 提取的原始 DEX，逐个与 APK 内文件核对。 |
| `6.6.7/link/` | 6.6.7 连接相关专项反编译输出。 |
| `6.6.7/oaf/` | 6.6.7 OAF 协议相关专项反编译输出。 |
| `6.6.7/targeted/` | 各适配阶段以 `-667.java` 标识的官方类拆解，保留原研究目录层级，便于区分同名文件。 |
| `6.6.7/native/` | 已提取的原生库文件，不代表 APK 内全部原生库。 |
| `6.6.7/ui-resources/` | 已提取的原版 UI 资源归档，包括编译资源表、布局等；这是资源包，不能作为应用安装。 |
| `inventory.json` | 来源目录、文件数量、大小、6.6.7 源 APK 与各 DEX 的 SHA-256。 |

6.6.7 适配来源为 `6.6.7_097c6ef_260803`，源 APK SHA-256：

```text
d8163ec849de6ee121171d1d1312b05f1500c8d4ec225c19f949042ae185aeaf
```

## 阅读方式

反编译结果用于查看原实现、资源引用和协议结构，不是官方原始开发工程。混淆名称、JADX 生成的别名、反编译失败方法和不完整类型信息均按现有输出保留，不能直接作为完整应用编译。

查找当前适配依据时，优先查看 `6.6.7/`。旧输出的类名与方法名可能不同，不应与新版本混用。独立应用的可构建源码和依赖准备方法见 [项目说明](../README.md)。

这里只包含 APK 静态拆解产物，不包含手机导出的健康数据库、账号信息、配对凭据、运行日志或截图。原文件保持不变；Java 文件按 UTF-8 读取验证，二进制文件直接复制。
